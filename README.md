# lotto-safe-auto-buy

> **Keep the odds above zero. Automate the consistency.** — Safe weekly auto-buy for Korean Lotto 6/45 & Pension 720+, running on GitHub Actions. Never over your limit, never pays twice.

동행복권 **로또 6/45 · 연금복권720+** 를 매주 자동으로 사는 도구입니다.
GitHub Actions 에서 돌아서 PC 를 켜 둘 필요가 없고, **브라우저만으로** 시작할 수 있어요.

---

## 왜 만들었나

**1. 가능성은 0이 아니게.**
로또 1등 확률은 814만분의 1이에요. 작지만 0은 아니죠. 사지 않으면 그 작은 가능성마저 0이 됩니다.

**2. 꾸준함은 자동으로.**
사람은 까먹고, 귀찮아하고, 기분 따라 더 사거나 안 사요. 그래서 꾸준함은 사람이 아니라 시스템에 맡겼어요.

**3. 대신 한도는 단단하게.**
복권 자동화의 진짜 위험은 당첨이 안 되는 게 아니라 **더 사게 되는 것**이에요. 버튼 두 번, 재시도 한 번, "이번 주는 좀 더".
그래서 이 도구는 하나를 약속합니다.

> **정한 한도보다 더 사지 않는다. 같은 회차를 두 번 사지 않는다.**

## 시작하기 (클릭 4번)

> 준비물: GitHub 계정 · 예치금을 충전한 동행복권 계정 · (알림을 받으려면) 텔레그램 봇

**① 내 레포 만들기**
이 페이지 오른쪽 위 **[Use this template] → Create a new repository** → 이름을 정하고 **Private** 을 고른 뒤 만들기.

<!-- 이미지: use-template.png -->

> Private 으로 만들어야 실행 기록(회차·예치금)이 남에게 보이지 않아요.

**② 비밀값 넣기 (한 번에)**
내 레포 → **Settings → Secrets and variables → Actions → New repository secret**
- Name: `LOTTO_SECRETS`
- Secret: 아래를 채워서 붙여넣기
  ```
  DH_ID=동행복권아이디
  DH_PW=동행복권비밀번호
  TELEGRAM_TOKEN=텔레그램봇토큰
  ```
  알림을 안 받으면 `TELEGRAM_TOKEN` 줄은 지워도 돼요.

<!-- 이미지: secrets.png -->

**③ (알림 받을 때만) 내 봇에게 아무 말이나 한 번 보내기**
텔레그램에서 [@BotFather](https://t.me/BotFather) → `/newbot` 으로 봇을 만들고, 받은 토큰을 ② 에 넣은 뒤, 그 봇에게 "안녕" 한 번.
채팅 ID 는 설정 단계가 자동으로 찾아요.

<!-- 이미지: botfather.png -->

**④ 설정 실행**
내 레포 → **Actions** 탭 → 왼쪽 **"① 설정"** → **Run workflow** → 고르고 실행

| 항목 | 선택지 |
|---|---|
| 무엇을 살까요? | 둘 다 / 로또만 / 연금만 |
| 로또 회차당 게임 수 | 1 – 5 (1게임 = 1,000원) |
| 연금복권 구매 방식 | 매주 직접 구매 / 5회차 예약 (실험적) |
| 텔레그램 알림 | 받음 / 안 받음 |

<!-- 이미지: setup-form.png -->

설정은 **구매하지 않고** 로그인 · 예치금 · 텔레그램 연결만 확인한 뒤, 모두 통과하면 자동 구매를 켭니다.
결과는 그 실행 페이지에 표로 나와요.

| 단계 | 결과 |
|---|---|
| 로그인 확인 (구매 안 함) | ✅ 예치금 2만원 · 이번 회차 로또 0게임 |
| 텔레그램 | ✅ 연결됨 |
| 자동 구매 켜기 | ✅ 매주 월요일 오전 |

**끝.** 이제 매주 알림만 와요.

- 설정을 바꾸려면 **"① 설정"** 을 다시 실행
- 끄려면 **"② 멈춤"** 실행
- 직접 확인하려면 **"구매"** 워크플로를 손으로 실행 (기본값이 **시험 실행** 이라 사지 않아요)

> Actions 가 꺼져 있다고 나오면 Actions 탭의 초록 버튼을 한 번 눌러 켜 주세요.

## 일정

| 언제 (KST) | 무엇 |
|---|---|
| 월 09:10 (+ 0-30분 랜덤) | 이번 회차 구매 |
| 수 09:10 | 보충 실행 — 이미 샀으면 로그인도 안 하고 끝 |
| 목 20:30 · 토 21:30 · 일 10:00 | 결과 확인 · 알림 |

GitHub 이 예약 실행을 몇 분에서 몇십 분 늦게 돌릴 때가 있어서, 마감(로또 토 20:00 · 연금 목 17:00) 직전은 피했어요.

## 안전장치

| 장치 | 하는 일 |
|---|---|
| **결제 재시도 없음** | 결제 요청은 응답이 늦어도 다시 보내지 않아요. 두 번 사는 것보다 한 번 놓치는 게 나아요. (결제 요청을 실패 시 재전송하는 구현도 있어요) |
| **결제 직전 시도 기록** | 결제 요청 *전에* 시도를 `state` 브랜치에 기록하고 푸시해요. 기록을 못 남기면 사지 않아요. 이미 기록된 회차는 다시 사지 않아요 |
| **회차당 한도 재확인** | 결제 직전마다 사이트 구매내역 · 예약내역 · 내 기록 중 가장 큰 값으로 이번 회차 장 수를 다시 세요. 하나라도 못 세면 안 사요 |
| **한 번에 하나만** | 모든 워크플로가 같은 `concurrency` 그룹이라 동시에 돌지 않고, 도는 중인 실행을 취소하지도 않아요 |
| **로그인 최소화** | 할 일이 없으면 로그인하지 않아요. 예약 실행은 로그인 전에 0-30분 랜덤 대기 (규칙적 호출 줄이기) |
| **로그인 실패 시 정지** | 비밀번호 오류 1번, 그 밖의 로그인 실패 연속 2번이면 멈추고 알려요 (5번 틀리면 계정이 잠기니까). "① 설정" 을 다시 실행하면 풀려요 |
| **계정 탈취 탐지** | 내가 안 산 주문 · 다른 복권 구매 · 설명 안 되는 예치금 감소 · 되던 로그인이 비밀번호 오류로 바뀜 → 🚨 알림 + 그 실행은 구매 중단 |
| **회차 대조** | 날짜로 계산한 회차와 사이트 회차가 다르면 (명절 휴무 등) 사지 않아요 |
| **판매 시간** | 매일 00-06시 · 로또 토 19:30 이후 · 연금 목 16:30 이후엔 사지 않아요 |

## AI 는 돈 버튼을 누르지 않는다

구매는 매번 같은 결과를 내는 스크립트가 합니다. 테스트로 고정할 수 있어야 "두 번 사지 않는다"를 약속할 수 있거든요.

Claude Code 를 쓴다면 시작을 도움받을 수 있어요 (선택). 아래를 붙여넣으면 ① ④ 단계와 결과 확인을 대신 해줘요.
**비밀번호는 Claude 에게 말하지 말고 ② 단계에서 브라우저로 직접 넣으세요.**

```
lotto-safe-auto-buy 템플릿으로 내 비공개 레포를 만들고 시작을 도와줘.
1) gh repo create <내레포> --private --template mopil/lotto-safe-auto-buy
2) Settings → Secrets 페이지를 브라우저로 열어줘 (LOTTO_SECRETS 는 내가 직접 넣을게 — 비밀번호를 나한테 묻지 마)
3) 내가 다 넣었다고 하면, 무엇을 살지·로또 게임 수·연금 방식·알림을 물어보고 "① 설정" 워크플로를 그 값으로 실행해줘
4) 실행 결과 요약을 읽고 설명해줘. 구매 워크플로는 dry_run=true 로만 돌려줘
```

## 비밀값과 개인정보

- `LOTTO_SECRETS` 는 GitHub 이 암호화해서 저장하고, **레포 주인도 다시 볼 수 없어요** (덮어쓰기만 가능)
- 로그에 찍히지 않게 실행마다 값마다 가립니다 (`::add-mask::`)
- 구매 기록 · 시도 기록은 내 레포의 `state` 브랜치에만 남아요. **레포를 Private 으로 두세요**

## 주의

- **복권은 기대값이 마이너스인 오락이에요. 잃어도 괜찮은 금액만.**
- 이 도구는 동행복권과 관련이 없는 비공식 도구예요. 사이트 약관(반복·규칙적 호출 금지 등)을 확인하고, 계정 · 예치금 관리 책임은 사용자에게 있어요
- GitHub Actions 서버는 해외에 있어요. 동행복권이 해외 접속을 막으면 동작하지 않아요 — "① 설정" 의 로그인 확인에서 바로 드러나요
- 연금 **5회차 예약** 은 실험 기능이에요 (실제 예약 경로는 아직 충분히 검증되지 않았어요). 확실한 쪽은 "매주 직접 구매" 예요
- 사이트가 바뀌면 멈출 수 있어요. 이때도 모르는 상태로 사지 않고, 멈추고 알리는 쪽을 택해요

```bash
export DH_ID=... DH_PW=...                 # 또는 LOTTO_SECRETS
FORM_BUY=둘\ 다 FORM_LOTTO_GAMES=1 FORM_PENSION_MODE=매주\ 직접\ 구매 FORM_TELEGRAM=안\ 받음 \
  python lotto_safe/configure.py setup      # 로그인 확인 + 설정 저장 (상태 폴더 기본값: ~/.lotto-safe)
python lotto_safe/lotto.py buy --dry-run   # 사지 않고 할 일만
python tests/test_lotto.py && python tests/test_cloud.py
```
